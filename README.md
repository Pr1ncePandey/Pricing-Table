# Pricing Table

This repository contains a responsive pricing table designed with HTML and CSS. The pricing table can be used to display different pricing plans for products or services.

## Table of Contents

- [Features](#features)
- [Installation](#installation)
- [Usage](#usage)
- [Contributing](#contributing)
- [License](#license)

## Features

- Fully responsive design
- Simple and clean layout
- Easy to customize

## Installation

To use this pricing table in your project, follow these steps:

1. Clone the repository:
    ```bash
    git clone https://github.com/Pr1ncePandey/Pricing-Table.git
    ```

2. Navigate to the project directory:
    ```bash
    cd Pricing-Table
    ```

## Usage

To integrate the pricing table into your project, you can include the HTML and CSS files in your project directory.

1. Copy the HTML structure from `index.html` to your HTML file.
2. Copy the CSS styles from `style.css` to your CSS file.

You can also customize the table to fit your needs by modifying the HTML and CSS files.
